## Projetos

### 01 — LogiData | Processamento de Dados Logísticos

**Status:** Em desenvolvimento

Projeto desenvolvido em Python para simular o processamento de registros de pedidos recebidos de um sistema logístico.

A proposta é trabalhar com dados brutos, identificar inconsistências, aplicar regras de validação e gerar indicadores operacionais.

**Funcionalidades em desenvolvimento:**

- Leitura e separação de registros.
- Padronização de informações.
- Validação de status e valores.
- Identificação de registros inconsistentes.
- Controle de pedidos entregues, pendentes e cancelados.
- Cálculo de faturamento e ticket médio.
- Tratamento de erros durante o processamento.

**Conceitos praticados:**

`for` · `while` · `if/elif/else` · `break` · `continue` · `split()` · `strip()` · `try/except` · operadores lógicos · conversão de tipos

**Próximas evoluções previstas:**

1. Finalizar e testar as regras de validação.
2. Refatorar o código utilizando funções.
3. Trabalhar com arquivos CSV.
4. Organizar registros válidos e rejeitados.
5. Integrar o processamento com PostgreSQL.

## Metodologia de estudo

Minha abordagem prioriza a prática e a compreensão dos conceitos.

Procuro estudar um assunto, desenvolver exercícios, experimentar diferentes soluções e revisar os erros encontrados.

Durante esse processo, busco compreender não apenas **como fazer algo funcionar**, mas também **por que determinada solução funciona e quais são suas limitações**.

Os códigos publicados representam diferentes momentos do aprendizado. Por isso, algumas implementações poderão ser revisadas, refatoradas ou substituídas conforme novos conhecimentos forem adquiridos.
